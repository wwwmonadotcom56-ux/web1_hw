# دليل فعاليات الجامعة الافتراضية — BWP401

## ملفات المشروع
- `index.html`: الرئيسية، التصنيفات، الفعاليات البارزة، أحدث الفعاليات وأعضاء الفريق.
- `events.html`: كل الفعاليات مع البحث والفلترة حسب التصنيف والتاريخ والموقع.
- `event.html`: تفاصيل الفعالية حسب `?id=1` إلى `?id=6`، زر تقويم ومشاركة.
- `about.html`: الهدف والرؤية والرسالة والقيم والفريق وسياسات النشر.
- `contact.html`: نموذج تواصل مع تحقق من الاسم والبريد والرسالة ورسائل Bootstrap Alerts.
- `assets/css/styles.css`: الهوية البصرية والتصميم المتجاوب.
- `assets/js/main.js`: الفلترة والسلايدر والتحقق والتقويم والمشاركة.

## التشغيل
افتح `index.html` في متصفحك، أو استخدم Live Server في Visual Studio Code. Bootstrap والخط والصور تُحمّل عبر الإنترنت من CDN ومصادر صور خارجية.

## بيانات الفريق
قبل التسليم، استبدل جميع العناصر بين الأقواس المربعة في `index.html` و`about.html` بأسماء وأرقام جميع المشاركين الحقيقيين. أضف صفوفاً إضافية إذا لزم الأمر.

## حدود النسخة التجريبية
الفعاليات والمواعيد والأماكن بيانات توضيحية وليست إعلانات رسمية. نموذج التواصل يتحقق في المتصفح فقط ولا يرسل بريداً حقيقياً. مكان الخريطة تمثيل ثابت وليس خريطة مباشرة. صور Unsplash تحتاج إلى اتصال بالإنترنت.

## نشر الموقع مجاناً على GitHub Pages
1. سجّل الدخول إلى https://github.com/.
2. أنشئ مستودعاً جديداً باسم مثل `bwp401-event-guide` واجعله Public.
3. ارفع محتويات هذا المجلد إلى جذر المستودع، بحيث يكون `index.html` في الجذر.
4. افتح **Settings → Pages**.
5. في **Build and deployment** اختر **Deploy from a branch**.
6. اختر الفرع `main` والمجلد `/(root)` ثم **Save**.
7. انتظر ظهور رابط GitHub Pages في الصفحة نفسها، وافتحه واختبر جميع الصفحات. الرابط عادة بالشكل `https://USERNAME.github.io/REPOSITORY/`.
8. استخدم الرابط الفعلي الذي يظهر في GitHub، ولا تخمّن الرابط قبل النشر.

## شرح التقنيات
- **HTML:** هيكل الصفحات باستخدام `header` و`main` و`footer` وبطاقات المحتوى.
- **CSS:** الألوان والخطوط والمسافات والتأثيرات وMedia Queries.
- **Bootstrap 5:** شبكة `container/row/col` وأشرطة التنقل والأزرار والنماذج والتنبيهات.
- **JavaScript:** الفلترة الفورية، سلايدر بطاقات على الهاتف، تحقق النموذج، مشاركة رابط الفعالية وتوليد ملف تقويم `.ics`.
- **التجاوب:** Bootstrap Grid مع Flexbox/Grid وMedia Queries.
